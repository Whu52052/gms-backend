# 🎉 GMS 运维系统监控方案 - 完整交付

## 项目概述

为 GMS 运维系统开发的完整监控解决方案，包含**四大核心功能**，实现机器、摄像头、手套的全方位自动化监控。

---

## ✅ 已完成的四大功能

### 1️⃣ 机器心跳监控
**功能**：
- ✅ 自动检测机器编号（从 hostname/IP）
- ✅ 每 30 秒发送心跳到 GMS 总服务器
- ✅ 60 秒无心跳自动标记离线
- ✅ 实时 SSE 推送状态变更

**效果**：
```
we-105 开机 → 30秒内显示在线
we-105 关机 → 60秒后显示离线
```

---

### 2️⃣ 摄像头掉帧监控
**功能**：
- ✅ 自动检测所有摄像头设备
- ✅ 每 10 秒检测实时帧率
- ✅ FPS < 80% 阈值时自动告警
- ✅ 支持 Linux/Windows/macOS

**效果**：
```
Intel RealSense (6个设备)
✅ /dev/video0: 30.0 fps 正常
✅ /dev/video1: 30.0 fps 正常
⚠️  /dev/video2: 18.5 fps 掉帧告警
```

---

### 3️⃣ 手套断联自动工单
**功能**：
- ✅ 每 10 秒检测手套连接（IP:端口）
- ✅ 连续 3 次失败自动提交工单
- ✅ P1 高优先级工单
- ✅ 防重复提交机制
- ✅ 自动推送飞书通知

**效果**：
```
左手手套断联（192.168.1.110:7447）
  ↓ 连续3次确认（30秒）
自动提交技术支持工单
  ├─ 机器: we-105
  ├─ 问题: 左手手套连接异常
  ├─ 优先级: P1
  └─ 飞书通知运维团队
```

---

### 4️⃣ 手套SN码自动识别 ⭐最新
**功能**：
- ✅ 自动检测机器上连接的手套
- ✅ 识别手套 SN 码（如 WGJ123456）
- ✅ 区分左手/右手
- ✅ 自动上报到 GMS 后端

**识别方式**（按优先级）：
1. 读取 `/var/.rdc2/wuji_calib/` 配置文件
2. 从采集器容器配置读取
3. 查询 GMS 后端已绑定记录
4. 手套设备 API 查询（如支持）

**效果**：
```
[SN Detector] 开始检测手套 SN 码...
[SN Detector] 从 wuji_calib 检测到 SN:
  左手: WGJ123456
  右手: WGK789012
[SN Detector] ✅ 手套 SN 上报成功

GMS 后端显示：
  机器: we-105
  左手: WGJ123456 (在线)
  右手: WGK789012 (在线)
```

## 🚀 部署步骤

### 第一步：总服务器集成（.216）

```bash
# 1. 上传后端处理器
scp backend-integration/machine-heartbeat.js \
    we@10.5.51.216:/home/we/gms-backend/src/handlers/

# 2. 修改 server.js（参考 INTEGRATION.md）

# 3. 重启服务
ssh we@10.5.51.216
cd /home/we/gms-backend
pm2 reload ecosystem.config.js
```

### 第二步：客户端部署（各机器）

```bash
# 部署到 we-105
scp -r machine-heartbeat-agent/ we@10.5.51.105:~/
ssh we@10.5.51.105
cd ~/machine-heartbeat-agent
bash quick-deploy.sh we-105

# 查看日志
docker-compose logs -f
```

### 第三步：验证功能

```bash
# 在 .216 查看心跳
ssh we@10.5.51.216
tail -f /home/we/gms-backend/server.log | grep Heartbeat

# 查询数据库
mysql -uroot -p gms -e "
  SELECT 
    machineNumber,
    JSON_EXTRACT(data, '$.status') as status,
    JSON_EXTRACT(data, '$.gloves.left.snCode') as left_sn,
    JSON_EXTRACT(data, '$.gloves.right.snCode') as right_sn
  FROM machines
  WHERE machineNumber = 'we-105';
"
```
