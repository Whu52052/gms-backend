## 🚀 快速部署流程

### 阶段一：后端集成（5分钟）

```bash
# 1. 上传心跳处理器
scp backend-integration/machine-heartbeat.js \
    we@10.5.51.216:/home/we/gms-backend/src/handlers/

# 2. 修改 server.js（参考 INTEGRATION.md）
#    - 导入模块
#    - 初始化处理器
#    - 添加路由
#    - 优雅关闭

# 3. 重启服务
ssh we@10.5.51.216
cd /home/we/gms-backend
pm2 reload ecosystem.config.js
```

### 阶段二：客户端部署（每台3分钟）

```bash
# 1. 复制项目到目标主机
scp -r machine-heartbeat-agent/ we@10.5.51.100:~/

# 2. SSH 登录并部署
ssh we@10.5.51.100
cd ~/machine-heartbeat-agent
sudo bash deploy.sh

# 3. 查看日志验证
docker-compose logs -f
```

### 阶段三：批量部署（一键完成）

```bash
# 编辑主机列表
vim batch-deploy.sh
# HOSTS=(10.5.51.100 10.5.51.101 10.5.51.102 ...)

# 执行批量部署
sudo bash batch-deploy.sh
```
